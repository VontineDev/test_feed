# Telegram 명령어 레퍼런스

봇이 실행 중이면 Telegram DM에서 아래 명령어를 입력할 수 있습니다.  
각 명령어는 `ALLOWED_CHAT_IDS`(또는 `TELEGRAM_CHAT_ID`)에 등록된 사용자만 사용 가능합니다.

---

## 시스템 정보

### `/status`

크롤러 현재 상태를 표시합니다.

**출력 항목:**
- 업타임 (시:분)
- 누적 수집 URL 건수
- 최근 24시간 수집 기사 수
- 최근 24시간 발생 신호 수 (BUY / SELL / WATCH)
- DB 연결 여부
- 현재 활성 백엔드 (Ollama / LM Studio)
- KOSPI / KOSDAQ 현재가 + 등락률 (KRX 직접 조회)

### `/today`

오늘 수집 현황과 최신 기사 5건을 표시합니다.

**출력 항목:**
- 카테고리별 수집 건수 (Reuters, 연합뉴스, 한국경제 등)
- 최신 기사 5건 (제목 + 발행 시각 + 링크)

## 매매 신호

### `/signals`

최근 매매 신호 10건을 표시합니다. 방향 필터를 추가할 수 있습니다.

```
/signals          — BUY/SELL/WATCH 모두
/signals buy      — BUY 신호만
/signals sell     — SELL 신호만
/signals watch    — WATCH 신호만
```

**출력 항목 (신호당):**
- 방향 아이콘 (🟢 BUY / 🔴 SELL / 🟡 WATCH)
- 기사 유형 배지 (📊 실적 / 📈 MA / 👥 경영 / 📋 애널리스트 / ⚖️ 규제 / 🛍️ 제품 / 🌍 거시)
- 강도 바 (⬛×strength + ⬜×(5-strength))
- 기사 제목 (70자 이내)
- 판단 근거 한 줄
- 관련 종목 (yfinance 심볼)
- 출처 + 발행 시각
- 원문 링크

**신호 강도 기준:**
- BUY/SELL: strength ≥ 2이면 알림 발송 (`is_actionable`)
- WATCH: strength ≥ 3이면 알림 발송

**HIGH CONFIDENCE 배지:**
- 🔥 *HIGH CONFIDENCE* — 신호 관련 종목이 해당 주 주봉 스크리너를 통과한 경우

## 백테스트

### `/backtest <mode> <start> <end> [옵션]`

과거 구간 백테스트를 실행합니다. DB에 저장된 신호·스크리너 데이터를 재현합니다.

```
/backtest ichimoku 2025-01-01 2026-01-01
/backtest stage    2025-06-01 2026-01-01 --market KOSDAQ
/backtest cross    2025-01-01 2026-01-01 --max 50
/backtest stage2   2025-01-01 2026-01-01
/backtest ichimoku 2025-01-01 2026-01-01 --hold-weeks 8
```

**모드:**

| 모드 | 설명 |
|------|------|
| `ichimoku` | 주봉 Ichimoku 7조건 재현 |
| `stage` | 일봉 Stage 1 조건 재현 (5/5 조건) |
| `cross` | Ichimoku + Stage 1 동일 주 교차 신호 |
| `stage2` | Stage 1 후 14일 이내 Stage 2 재진입 조건 |
| `compose` | Tier-1 조합전략 — 별도 형식 사용 (아래 참고) |

**compose 모드:**

```
/backtest compose <strategy> <start> <end> [market]
  strategy: AND-1 | AND-2 | SCORE-1 | FUNNEL-1 | ALL
```

| 전략 | 설명 | 샤프28d (25W01~26W24) |
|------|------|----------------------|
| `AND-1` | 이치모쿠 ∩ Stage2+ ∩ 수급 비동시매도 | 1.75 |
| `AND-2` | AND-1 ∩ 거래량 주내 중앙값 이상 | — (신호 희소) |
| `SCORE-1` | Stage·거래량·수급 z-score top-20/주 | 0.62 |
| `FUNNEL-1` | 수급 스크린 → 4주 내 이치모쿠 트리거 | 0.74 |
| `ALL` | 4전략 순차 실행 → 비교표 (샤프 내림차순) | — |

DB 연결(DSN) 필수. HTML 리포트 `reports/backtest/compose_*.html` 자동 저장.

**옵션:**

| 옵션 | 설명 |
|------|------|
| `--market KOSPI\|KOSDAQ\|ALL` | 대상 시장 (기본: ALL) |
| `--max N` | 최대 신호 수 제한 |
| `--hold-weeks N` | 보유 기간 (주). 기본: 1/4/13주 표준 기간 |
| `--tp1 <비율>` | 1차 익절 가격 비율 (예: `0.07` = +7%) |
| `--tp1-ratio <비율>` | 1차 익절 시 청산 비율 (예: `0.5` = 50%) |
| `--trail <비율>` | 트레일링 스탑 비율 (예: `0.05` = -5%) |
| `--stop <비율>` | 손절 비율 (예: `0.08` = -8%) |

**출력 지표:**
- 신호 수, 승률 (7d/28d/91d)
- 평균·중앙값 수익률
- KOSPI 대비 초과수익률
- 샤프비율 (연환산)
- MDD (최대 낙폭)
- 거래비용 반영 (왕복 0.21%)

## 스크리너

### `/screener`

최신 강세 후보 발굴 결과를 DM으로 조회합니다. DB에 저장된 가장 최근 주 결과를 표시합니다.

**출력 항목 (종목당):**
- 종목명 + 코드 + 섹터
- 현재가, 20주선/60주선/120주선
- 구름 상단
- 정배열(↑) / Enhanced 배지 (전환선>기준선·둘다상승)
- 갭점프 여부

### `/scan`

주봉 스크리닝을 즉시 실행합니다. 전 종목 실시간 스캔 후 결과를 저장하고 DM으로 발송합니다.  
소요 시간: `SCREENER_WORKERS` 설정에 따라 10~20분.  
스캔 중 두 번째 `/scan` 명령은 무시됩니다.

## 워치리스트

### `/watchlist`

거래대금 워치리스트를 즉시 조회합니다. 매일 17:00 KST 정기 발송을 기다리지 않고 언제든 확인할 수 있습니다.

**출력 항목 (종목당):**
- 종목명 + Stage + D+N (진입 후 경과일)
- `[마지막 추적일]` — D+10 이상 (자동 추적 만료 예정)
- 거래대금 비율 (오늘 거래량 / Stage 1 진입 거래량)
  - ✅ ≥100% / ⚠️ 60~100% / ❌ <60% (랠리 소멸)
- 전일 대비 변화 (`+5%▲` / `-8%▼`)
- 외국인·기관 스트릭 (🔵 순매수 / 🔴 순매도)
- Ichimoku 주봉 통과 여부 (☁️)

## 거래 저널 (Trade Journal)

### `/buy <코드> <가격> <수량> [YYYYMMDD]`

진입 기록을 저장합니다. 모의투자 추적용이며 실제 주문이 아닙니다.

```
/buy 005930 70000 100
/buy 005930 70000 100 20260115
```

### `/sell <코드> <가격>`

청산 기록을 저장합니다. FIFO 방식으로 보유분을 차감합니다.

```
/sell 005930 73500
```

### `/port`

현재 보유 종목과 미실현 P&L을 표시합니다.

### `/pnl [week|month|all]`

실현 손익 요약을 표시합니다.

```
/pnl
/pnl week
/pnl month
/pnl all
```

## 모의투자 (Kiwoom Paper Trading)

`KIWOOM_MOCK_APPKEY` 등 키움 환경변수가 설정되어야 실제 모의주문이 발행됩니다.

### `/paper`

현재 오픈 포지션 현황을 표시합니다.

**출력 항목:**
- 모델별 포지션 (Stage / KOSDAQ / Cross / Ichimoku)
- 진입가, 현재가, 미실현 수익률
- 슬리피지 (이론가 대비 실제 체결가 차이)

### `/paper_perf`

모의투자 누적 성과를 표시합니다.

**출력 항목:**
- 승률 (청산 완료 포지션 기준)
- 평균 수익률
- 평균 슬리피지
- 이론 수익률 vs 실제 수익률 비교

### `/paper_exit <종목코드>`

특정 종목을 수동으로 즉시 청산합니다.

```
/paper_exit 005930
```

## 정기 발송 알림 (스케줄)

봇 명령어 외에 스케줄에 따라 자동 발송되는 알림입니다.

| 시각 (KST) | 내용 |
|------------|------|
| 매 15분 | 뉴스 수집 사이클 — 신호 감지 시 즉시 발송 |
| 매일 16:30 | 일봉 3단계 분류기 결과 — 추세 단계 + 강세 후보 교차 비교 |
| 매일 17:00 | 거래대금 워치리스트 일보 |
| 매일 17:00 | Stage 1→2 전환 감지 시 별도 알림 |
| 매일 17:00 | 랠리 소멸 경고 (3거래일 연속 vol_ratio < 0.6) |
| 매주 일요일 20:30 | 주봉 스크리너 결과 — 전 종목 Ichimoku 스크리닝 |
| 매주 월요일 09:00 | 주간 백테스트 리포트 |
