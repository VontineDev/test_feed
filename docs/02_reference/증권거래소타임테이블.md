# 증권거래소 타임테이블 및 대시보드 데이터 전략

## 시장 운영 시간

| 시간대 | 한국거래소 (KRX) 운영 | 넥스트레이드 (NXT) 운영 | 비고 / 특징 |
|--------|----------------------|------------------------|------------|
| 08:00 ~ 08:30 | 장 개시전 시간외종가 (08:30까지) | 프리마켓 (일반 지정가) | 출근길 거래 가능 시간 |
| 08:30 ~ 08:50 | 장 개시전 동시호가 접수 (체결X) | 프리마켓 (일반 지정가) | NXT는 장전 계속 체결됨 |
| 08:50 ~ 09:00 | 장 개시전 동시호가 접수 (체결X) | 거래 일시 중단 (10분간) | KRX 시가 결정을 위해 휴장 |
| 09:00 ~ 15:20 | 정규시장 (실시간 매매) | 메인마켓 (실시간 매매) | 양 시장 경쟁 매매 진행 |
| 15:20 ~ 15:30 | 장 마감 동시호가 (체결X) | 거래 일시 중단 (10분간) | KRX 종가 결정을 위해 휴장 |
| 15:30 ~ 15:40 | 장후 시간외종가 준비 단계 | 애프터마켓 (단일가) | 당일 KRX 종가로 매매 체결 |
| 15:40 ~ 16:00 | 장후 시간외종가 매매 | 애프터마켓 (일반 지정가) | 퇴근길 본격 거래 시작 |
| 16:00 ~ 18:00 | 시간외 단일가 매매 (10분 주기) | 애프터마켓 (일반 지정가) | NXT는 실시간 지정가로 체결 |
| 18:00 ~ 20:00 | 당일 매매 전면 종료 | 애프터마켓 (일반 지정가) | 밤 8시까지 야간 거래 가능 |

## 대시보드 데이터 소스 전략 (히트맵 / Top)

| 시간대 (KST) | 데이터 소스 | API | 내용 |
|-------------|------------|-----|------|
| 00:00 ~ 08:59 | `daily_market_snap` (전일 20:10 수집) | — | 전일 KRX+NXT 최종 합산 종가 |
| 09:00 ~ 15:39 | Kiwoom 실시간 | ka10032 (stex_tp=3) | 정규장 + 마감 동시호가 체결 후 종가 확정분 |
| 15:40 ~ 16:09 | Kiwoom NXT 실시간 | ka10098 | NXT 애프터마켓 진행 중 실시간 |
| 16:10 ~ 20:09 | `daily_market_snap` (당일 16:10 수집) | — | KRX 정규장 + NXT 16:10까지 누적 |
| 20:10 ~ 익일 08:59 | `daily_market_snap` (당일 20:10 수집) | — | NXT 20:00 종료 후 완전한 KRX+NXT 최종값 |

### 스케줄러 잡

| 잡 ID | 실행 시각 (KST) | 설명 |
|-------|----------------|------|
| `daily_market_snap` | 평일 16:10 | ka10032 전종목 → daily_market_snap (중간 스냅샷) |
| `daily_market_snap_final` | 평일 20:10 | ka10032 재조회 → daily_market_snap upsert (최종값 덮어쓰기) |
| `daily_aftermarket_sync` | 평일 16:05 | ka10098 NXT 애프터마켓 → aftermarket_snap |

### 캐시 무효화 로직

`_cache_is_valid()` 함수가 `market_open` / `is_nxt` 상태 태그를 비교하여
시장 상태 전환 시(장중→NXT→스냅샷) 캐시를 즉시 무효화한다.

- `_is_market_open()`: 평일 09:00 ~ 15:39 KST
- `_is_nxt_open()`: 평일 15:40 ~ 16:09 KST
- 나머지 시간: `daily_market_snap` DB 조회 (TTL 30분)
