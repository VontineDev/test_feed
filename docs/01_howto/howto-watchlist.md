# 거래대금 워치리스트 가이드

Stage 1 진입 종목을 14캘린더일 동안 매일 추적합니다. 거래대금 건강도·수급 스트릭·Ichimoku 통과 여부를 통합하여 Telegram 일보를 발송하고, `/watchlist` 명령어로 언제든 온디맨드 조회할 수 있습니다.

---

## 동작 원리

```
매일 17:00 KST
    ↓
Stage 1 진입 후 14일 이내 종목 조회
    ↓
yfinance에서 오늘 거래량 병렬 수집
    ↓
거래대금 비율 = 오늘 거래량 / Stage 1 진입 거래량
    ↓
외국인·기관 streak, Ichimoku 주봉 통과 여부 조합
    ↓
확신도 순 정렬 → Telegram 일보 발송
```

워치리스트에 종목이 없으면 "워치리스트 없음" 메시지만 발송합니다.

---

## 일보 포맷

```
📊 거래대금 워치리스트 (2026-05-20, 장 마감)

삼성전자(005930) — Stage 1, D+3
  거래대금 비율 +45% ✅
  전일 대비 +8%▲
  🔵 외국인 +3일 / 🔵 기관 +2일
  ☁️ 일목: 구름 상단 ✅

셀트리온(068270) — Stage 2, D+8
  거래대금 비율 -15% ⚠️
  전일 대비 -5%▼
  🔴 외국인 -1일 / ❓ 기관 N/A
  ☁️ 일목: 통과 ❌

LG에너지솔루션(373220) — Stage 1, D+10 [마지막 추적일]
  거래대금 비율 -45% 소멸 ❌
  전일 대비 -12%▼
  🔴 외국인 -2일 / 🔴 기관 -1일
  ☁️ 일목: N/A
```

### 각 항목 해석

| 항목 | 해석 |
|------|------|
| `D+N` | Stage 1 진입 후 경과일 |
| `[마지막 추적일]` | D+10 이상 — 자동 추적이 곧 만료됩니다 |
| 거래대금 비율 ✅ | ≥ 100% — 오늘 거래량이 진입 당일 이상 |
| 거래대금 비율 ⚠️ | 60~100% — 거래 유지 중 |
| 거래대금 비율 ❌ 소멸 | < 60% — 매집이 약화되고 있습니다 |
| 전일 대비 ▲▼ | 전날 대비 거래대금 비율 변화 (어제 데이터가 없으면 미표시) |
| 🔵/🔴 스트릭 | 외국인·기관 연속 순매수(🔵)/순매도(🔴) 일수 |
| ☁️ N/A | 이번 주 주봉 스크리닝 결과 없음 |

### 확신도 정렬

일보 내 종목 순서는 확신도 점수 기준입니다:

```
확신도 = vol_ratio + flow_score × 0.2
```

`flow_score`는 `stage_classifications` 테이블에 저장된 수급 컨빅션 점수(-1.0 ~ +1.0)입니다. `flow_score`가 없으면 streak 기반 폴백을 사용합니다:

```
확신도(폴백) = vol_ratio + (외국인 순매수 ? +0.1 : 0) + (기관 순매수 ? +0.1 : 0)
```

거래대금 비율이 높고 외국인·기관 수급이 지속되는 종목이 상단에 위치합니다.

## 자동 알림

정기 일보 외에 특정 조건이 충족되면 즉시 별도 알림이 발송됩니다.

### Stage 2 전환 알림

Stage 1 진입 종목이 당일 Stage 2로 전환되면 즉시 발송합니다.

```
🟢 Stage 2 전환 확인 (2026-05-20)

삼성전자(005930) — D+5 → Stage 2 진입
```

### 랠리 소멸 경고

거래대금 비율이 3거래일 연속 < 60%이면 경고를 발송합니다.

```
❌ 랠리 소멸 경고 (2026-05-20)
3거래일 연속 진입비 -40% 이상

셀트리온(068270) 오늘 비율 -52%
```

---

## 온디맨드 조회

정기 발송(17:00 KST)을 기다리지 않고 언제든 현황을 확인할 수 있습니다.

```
/watchlist
```

장 중(09:00~15:30)에 조회하면 오늘 거래량이 아직 확정되지 않으므로 vol_ratio가 낮게 나올 수 있습니다. 장 마감 후 조회가 가장 정확합니다.

## CLI 즉시 실행

```bash
python run_scheduler.py --once watchlist
```

## 데이터 저장소

워치리스트 관련 DB 테이블:

| 테이블 | 내용 |
|--------|------|
| `stage_classifications` | Stage 1/2/3 분류 이력 — 워치리스트의 원본 데이터 |
| `watchlist_vol_log` | 일별 vol_ratio 이력 — 전일 대비 delta, 랠리 소멸 감지에 사용 |

```sql
-- 특정 종목 vol_ratio 이력 조회
SELECT trade_date, vol_ratio, s1_vol
FROM watchlist_vol_log
WHERE ticker = '005930.KS'
ORDER BY trade_date DESC
LIMIT 14;
```

## 트러블슈팅

**워치리스트는 있는데 일보가 발송되지 않는 경우:**
- 17:00 KST 스케줄 확인: 스케줄러가 실행 중인지 확인
- 로그: `grep "워치리스트" logs/run.log | tail -20`

**거래대금 비율이 모두 N/A인 경우:**
- yfinance에서 거래량을 가져오지 못했습니다. 인터넷 연결 확인
- 장 휴일(공휴일)에는 volume이 0 또는 null로 반환될 수 있습니다

**D+10 이후에도 종목이 남아있는 경우:**
- `get_stage1_watchlist(days=14)`가 14캘린더일 이내 종목을 모두 조회합니다. D+10 이상이면 `[마지막 추적일]` 마커가 표시됩니다.
- D+14 이후에는 자동으로 목록에서 사라집니다.
